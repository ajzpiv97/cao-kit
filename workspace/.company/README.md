# `.company` workspace

This directory is the persistent coordination layer for the CAO agent-company prototype.

```text
contracts/   Operating rules
prompts/     Captain runbooks
 tasks/      Approved task definitions
artifacts/   Engineering and general deliverables
research/    Research deliverables
reviews/     Independent reviews
decisions/   Captain syntheses and human decisions
handoffs/    Intermediate cross-agent packets
```

Commit useful artifacts and contracts to Git. Never store secrets here.
