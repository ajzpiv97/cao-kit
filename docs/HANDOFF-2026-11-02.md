## What got done (commits 3637831 to a60146e)

- **Lint:** fixed all 90 ruff errors in `scripts/validate_e2e.py`. The harness now ignores `__pycache__` files in its source-modified check.
- **Two-path captain** (`profiles/startup_captain.md`, `src/caokit/data/roles/general.md`):
  - Fast path: a clear task uses at most 2 agents (author plus cross-provider reviewer), needs no approval stop, and the human reviews the output afterwards.
  - Plan path: required for auth/secrets, data deletion or migration, new dependencies, anything external, ambiguity, or more than 2 agents. The captain presents a Team plan and the human approves it.
  - Every plan must carry a per-agent estimate, including the captain. The unit is a range of fresh tokens (input + output + cache writes, no cache reads) with a low/med/high label and a basis.
  - A researcher is allowed only in planning, once.
  - In plan mode, approval is forced, so the fast path is only fast outside plan mode.
  - Workers act freely and ask the captain via `send_message`; the captain asks the human. There is no cap on clarification rounds yet.
- **Task template:** new "Team plan" section (also in `STATE_CONTRACT`: fast-path `PROPOSED -> APPROVED`) and a `Depends on:` header line.
- **`scripts/token_usage.py`:** reads Claude transcripts per session and attributes them to a role by `.company/` write paths. The harness writes `evidence/token-usage.md` and `.json`. Antigravity (`agy`) leaves no token data.
- **`caokit tasks`** (`src/caokit/tasks.py`, `tests/test_tasks.py`):
  - `caokit tasks [repo]` lists open tasks and what blocks each (blocked until every dependency is `ACCEPTED`). It errors on a dependency loop. `--all` includes finished tasks.
  - `caokit tasks archive [repo]` moves `ACCEPTED`, `CANCELLED` and `FAILED` task files into `.company/tasks/archive/`. `--delete` removes them instead. It is idempotent.
  - The captain tells the human to run `archive`, since it has no shell.
- Reinstalled the legacy profiles into CAO with `scripts/30-install-cao-profiles.sh`. The installed captain has the archive rule. A running captain session must be restarted to pick it up.

Checks at `a60146e`: 159 unit tests, ruff and mypy strict all pass. Run tests with `PYTHONPATH=src python3 -m unittest discover -s tests -t .`. Use `uvx ruff` and `uvx mypy` (the PATH ruff is the wrong architecture).
